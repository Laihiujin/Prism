# 已合并到 Prism 封面与标题工作室

加载 `prism-cover-studio`，统一制作平台标题、简介、标签、封面与横竖版本。如果有品牌规范更好。
项目源位于 `docs/hermes-skills/prism-cover-studio/`，Hermes creative 分类同名技能包含完整流程。
每次生成/修订必须实际引用核对过的原始产品图；不能从模型记忆或缓存图重画产品，也不能用未融合的叠图冒充完成。各平台独立创意，不共用背景换字。
先出可检查样稿，用户要求过关后继续时等待明确批准。生成封面不等于发布，发布仍需相应授权与平台技能。
