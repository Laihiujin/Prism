Drop headshot photos of yourself here (PNG or JPG).

```
~/.claude/skills/video-thumbnail/assets/headshots/
```

These are sent to Gemini as reference images when generating thumbnails. The AI uses your likeness to composite you into the thumbnail.

Tips for best results:
- Clear, well-lit face
- Multiple angles and expressions give more options
- Shoulders-up or waist-up framing works best
- Transparent or simple backgrounds are ideal

The skill picks the first available headshot in this folder automatically. Photos placed here are **not** committed to git (see `.gitignore`) — this folder ships empty by design.
