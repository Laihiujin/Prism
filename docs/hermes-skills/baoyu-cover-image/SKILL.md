# 社媒封面设计与生成（Prism 适配）

## 先确定画面要传达什么

读取 `prism-social-content` 与目标平台发布技能。查看实际视频帧、产品或用户参考图，提取一个可证实的看点；人物身份、产品形态、结果与数字以素材为准。
将长标题压缩成手机上可辨认的一句封面文案。通常 4–10 字，可有一个短补充标签；不要把简介堆进画面。
已有创作授权时直接推进，用户指定风格优先；只有缺少决定性素材或目标不明确时再询问。

## 五维设计，而非只写“高级感”

1. **类型**：hero（人物/产品主视觉）、conceptual（概念）、typography（文字）、metaphor（隐喻）、scene（场景）、minimal（极简）。读取 [types](references/types.md)。
2. **配色**：选择一个主色、一个强调色和可读的文字色。按需从 `references/palettes/` 读取所选色系。
3. **渲染**：实拍素材优先保留真实主体；扁平、手绘、像素、粉笔等风格应与内容相符。读取 [风格预设](references/style-presets.md) 和 [兼容关系](references/compatibility.md)。
4. **文字**：无字、单标题、标题+副标题三选一；明确逐字内容、断行、位置、字体气质、底色/描边。避免关键字被人脸或边缘遮挡。
5. **情绪**：克制、均衡、强烈；通过明暗、空间、视线和强调色表达，不能凭空改变人物表情或捏造冲突。

内容不明确时可先内部比较“主体主导 / 问题主导 / 结果主导”三个方向，再选最忠于素材且最清晰的方案。用户要求多方案才实际生成多个候选。

## 平台构图

| 平台 | 推荐画面组织 | 注意 |
| --- | --- | --- |
| 抖音 | 单主体、强对比短标题、一眼识别的动作或结果 | 与视频开头一致，主信息避开边缘和覆盖控件 |
| B站 | 横向主体区+标题区，必要时用有依据的对照或步骤关系 | 内容信息具体；不能用无关夸张表情充当看点 |
| 小红书 | 竖向首图，清楚的人群/场景/价值；系列卡片转 `baoyu-xhs-images` | 控制信息密度，首图负责吸引，正文图负责解释 |
| 视频号 | 人物或场景清晰，标题克制且易转述 | 留出横竖裁切空间 |

先查发布器约束。当前 `generate_cover.aspect_ratio` 只允许 `3:4`、`4:3`：竖版用前者，横版用后者。它们是项目接口限制，不代表各平台官方标准。不能把上游默认 16:9/1:1 直接传进接口。
重要主体与标题尽量置于中部约 80% 区域，作为设计起点，实际仍需检查平台预览裁切。

## 提示词落盘与 Prism 执行

每个方向先保存完整提示词到本次任务输出目录的 `prompts/`，例如 `bilibili-cover.md`：

```text
平台与用途：[平台]视频封面
画布：[3:4 / 4:3]；主体区：[位置与占比]；标题区：[位置与范围]
参考主体：[素材中的真实人物/产品/场景]；保留：[身份、轮廓、服装、动作]
核心信息：[一个有素材依据的看点]
构图：[视觉焦点、主次关系、留白、裁切安全区]
类型/配色/渲染/情绪：[明确选择，主色与强调色]
准确文字：「[标题]」；断行：[方式]；字体：[气质]；文字对比：[底色/描边]
约束：不添加其他文字、水印、平台Logo；不改人物身份；不虚构结果。
```

需要参考图的构图细节可读 [基础提示词](references/base-prompt.md) 和 [视觉元素](references/visual-elements.md)。
MCP 调用 `generate_cover`：`file_id`、`platform_name`、`aspect_ratio`、`prompt`、`use_first_frame`。视频封面通常设置 `use_first_frame=true`；若首帧不具代表性，明确说明限制，不声称使用了接口未接收的外部参考图。
用 `get_cover_job(job_id)` 查结果；成功后 `list_material_covers(file_id)`，检查返回图片后用 `select_material_cover(file_id, cover_id)` 选用。
裁切使用 `adapt_material_cover(file_id, path, platform)`，`path` 是素材库相对路径。横竖布局需要重排时重新生成，不能靠拉伸完成。
CLI：`python prism_cli.py tool invoke <工具名> --json-file <参数文件>`。参数按当前工具目录为准。
统一使用 Prism 已配置图像服务，不执行上游 Codex 包装器或另装图片后端。

## 看图检查与修订

查看成品原图和约 320px 宽缩略图：标题是否逐字正确、焦点是否唯一、文字是否可读、主体是否忠于素材、裁切是否丢失信息。
发现错字先修改提示词，另存新候选再生成；不覆盖原候选。一次针对性重试仍失败就报告具体问题，给出减字或无字方案，不循环消耗生成额度。
交付平台、方向、比例、准确封面文案、提示词路径、job_id、实际封面路径/cover_id、是否已选用及未解决问题。提示词完成与图片生成完成分别报告；发布另按用户授权执行。
